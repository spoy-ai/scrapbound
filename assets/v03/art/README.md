# 0.3 玩法美术

六张静态 PNG 均为透明、裁去留白的游戏资源：

| 文件 | 用途 |
| --- | --- |
| `route_saw.png` | 裂甲重锯路线：红瓶盖锯、黄铜齿、加固木夹 |
| `route_thread.png` | 缝线纽扣路线：两颗青绿纽扣与金色缝线 |
| `route_coil.png` | 线圈工坊路线：铜线圈与线轴助手 |
| `overdrive.png` | 上紧发条主动爆发 |
| `musicbox.png` | 场中音乐盒事件 |
| `recycler.png` | 磁力回收机事件 |

动作元数据使用本目录 `animations.json`。其 `file` 是完整的 Godot `res://assets/v03/art/…` 路径，不需再次拼接 assets。每格保留固定参考画布；`pivot` 为归一化地面锚点。静态 PNG 已裁去画布，布局时不使用此锚点。

图片通过用户指定的 Ai-DF 调用 Seedream 5.0 Pro；视频使用 Seedance 2.5、明确请求 480P、4 秒、关闭声音、相同首尾帧约束。平台实际返回两段 640×640、24 fps、4.041667 秒的方形原片，取前 96 帧制作 4 秒循环。模型原始输出、请求参数、任务编号、参考帧、透明总览、动作接触表、动画预览和检验结果保存在 `source/v03/`。抽帧与抠背景离线完成，运行时不需要 Ai-DF。

生成脚本：`tools/v03_art.py`。离线制作脚本：`tools/v03_art_assets.py`。前者对已有请求先查状态，避免因超时重复提交。
